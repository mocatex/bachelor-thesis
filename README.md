# Bachelor Thesis

This is the Bachelor Thesis of Moritz Feuchter and Shpetim Veseli, submitted to the Zurich University of Applied Sciences (ZHAW) in June 2026. The thesis is titled "Quantum Machine Learning for Analyzing Galaxies" and explores the application of quantum machine learning techniques to the analysis of galactic data. The thesis is supervised by Prof Dr. Kurt Stockinger and Dr. Pavel Sulimov.

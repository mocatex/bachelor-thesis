\section{Declaration on the Use of Generative AI}
\label{sec:declaration_use_of_ai}

Generative AI systems and AI-based tools were used during the preparation of the thesis in a supporting role.
GitHub Copilot, as well as Claude Code were used to assist with program code development,
including code suggestions and implementation support. The use of these tools was limited
to code development and did not extend to the generation of thesis content or analysis.
Several AI Tools were used to support literature and source discovery, to improve and correct
the wording of the text, for proofreading, for explanations of technical concepts and for translation assistance.
All content generated with the support of these tools was reviewed, validated and adapted by the authors.
The authors remain fully responsible for the correctness, originality and integrity of the presented work.
